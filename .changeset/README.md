# Changesets

Run `pnpm changeset` for changes that affect either published package (`matchstick-ts` or
`hardhat-matchstick-ts`). Select the packages, choose the semver bump, and describe the
consumer-visible change.

Changesets are not required for documentation, tests, examples, or internal tooling changes that do
not alter a published package. See [RELEASING.md](../RELEASING.md) for what happens after merge.
